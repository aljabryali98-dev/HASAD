## 📖 نبذة عن النظام (Overview)

**نظام "حصاد" (Hasad ERP)** هو منصة سحابية/محلية مؤسسية متقدمة صُممت لتكون **المصدر الواحد للحقيقة (Single Source of Truth - SSOT)** لجميع بيانات وأنشطة الجمعيات التعاونية الزراعية، المجاميع الإنتاجية، فرسان وكوادر التنمية، ومحفظة القروض التمويلية البيضاء في الجمهورية اليمنية، مع ربط جغرافي لحظي شامل على مستوى (المحافظة ← المديرية ← العزلة ← القرية/المحلة).

---

## ✨ المميزات والوحدات المعمارية الرئيسية (Core Modules)

### 1. التقسيم الجغرافي والإداري الرباعي الذكي (4-Level Geography Hierarchy)
- تغطية شاملة لجميع محافظات الجمهورية اليمنية (22 محافظة)، 333 مديرية، و 2,613 عزلة/مركز.
- **المستوى الرابع الديناميكي (`sub_locations`):** إدارة القرى والمحلات والمناطق الفرعية مع كود تسلسلي فريد، وإمكانية الإضافة السريعة داخل أي نموذج، مع دعم استيراد ملفات Excel المجمعة.
- منتقي جغرافي رباعي مترابط ومتتالي (`<x-location-hierarchy-selector />`) يعمل عبر AJAX في كافة شاشات ونماذج النظام.

### 2. وحدة الجمعيات التعاونية (الملف الشامل 360° بـ 9 تبويبات)
- توليد تلقائي ذكي لكود الجمعية وفق النطاق الجغرافي: `ASS-{uzlah_code}-{seq}`.
- **الملف التفصيلي الشامل (9 Tabs):**
  1. **البيانات الأساسية:** المقر، الاتصال، البيانات التأسيسية.
  2. **البيانات القانونية والتنظيمية:** أرقام وتواريخ التراخيص وجهات المنح.
  3. **القيادة والإدارة:** أعضاء الهيئة الإدارية والرقابية مع حساب العمر تلقائياً من تاريخ الميلاد.
  4. **الأعضاء والمنتسبون:** إحصائيات الذكور والإناث والمستفيدين.
  5. **البيانات الاقتصادية والمالية:** رأس المال التأسيسي والحالي، وحساب إجمالي قيمة الأسهم تلقائياً.
  6. **المشاريع والأنشطة التعاونية:** ترابط تلقائي فوري يعرض كافة مشاريع الجمعية ومحاصيلها ومزارعيها.
  7. **الأصول والممتلكات:** السجلات المحاسبية والميزانيات المعتمدة.
  8. **محفظة القروض البيضاء:** متابعة مبالغ القروض والأرصدة المتبقية بنسبة فوائد 0%.
  9. **المتابعة والتقييم:** مؤشرات الأداء والتقييم المؤسسي.

### 3. وحدة المجاميع الإنتاجية (Productive Groups Dossier)
- ملف متكامل للمجموعة بـ 5 تبويبات تفصيلية.
- ربط بالميسرين الميدانيين عبر جدول وسيط (`group_facilitators`) مع عداد فوري لعدد المجاميع التي يقوم كل ميسر بتيسيرها.
- متابعة مساحات الإنتاج الزراعي، سلاسل القيمة، وقنوات التسويق.

### 4. بنك الكوادر والفرسان الموحد (Unified Personnel)
- تغطية تخصصات فرسان التنمية الـ 17 (فارس تنموي متطوع، بيطري، زراعي، مائي، مصادر وبذور، تسويق، إلخ).
- سجلات الباحثين، المدربين، المرشدين، وطلاب كليات الزراعة.
- احتساب تلقائي وديناميكي للعمر (`age`) وتوليد آلي للأكواد (`KNT-00001` / `PER-00001`).

### 5. محفظة القروض التمويلية البيضاء (0% Interest White Loans)
- إدارة التمويلات البيضاء (قروض حسنة بدون فوائد 0%) لتمكين المزارعين والجمعيات.
- **حساب تلقائي للرصيد المتبقي:** `loan_amount - paid_amount` دون تدخل يدوي.

### 6. مستكشف النطاق الجغرافي الشامل (360° Geo-Explorer)
- نافذة استكشاف تنفيذية تقوم بتجميع لحظي وتحليلي لكافة أنشطة ومشاريع وكوادر أي محافظة أو مديرية أو عزلة عبر الـ 34 قسماً في النظام.

### 7. لوحة الإحصائيات المركزية (KPI Dashboard)
- واجهة RTL متكاملة ومصممة بأحدث معايير تجربة المستخدم بخط "تجوال" (Tajawal).
- مؤشرات مباشرة ورسومية للجمعيات، المجاميع، المزارعين، والتمويلات.

## 🛠 المتطلبات التقنية (System Requirements)

- **PHP:** الإصدار 8.2 أو أحدث (مع إضافات `pdo_sqlite`, `mbstring`, `fileinfo`, `openssl`).
- **Composer:** الإصدار 2.x.
- **خادم الويب:** Apache / Nginx أو خادم PHP المدمج (`artisan serve`).
- **قاعدة البيانات:** SQLite (افتراضياً بدون إعدادات إضافية) أو MySQL / PostgreSQL.

## 🚀 التثبيت والتشغيل المحلي (Local Installation Guide)

```bash
# 1. استنساخ المستودع (Clone Repository)
git clone https://github.com/<USERNAME>/HASAD.git
cd HASAD

# 2. تثبيت الحزم والمكتبات (Install Dependencies)
composer install

# 3. إعداد ملف البيئة (Environment Setup)
cp .env.example .env
php artisan key:generate

# 4. بناء قاعدة البيانات وتشغيل التهيئة (Migrate & Seed)
php artisan migrate --seed

# 5. تشغيل خادم التطوير المحلي (Start Server)
php artisan serve
```

افتح المتصفح وتوجه إلى: `http://127.0.0.1:8000`
